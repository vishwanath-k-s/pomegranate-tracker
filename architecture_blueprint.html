4. Engineering Roadmap: Scaling Robustness, Accuracy & Reliability

Architectural upgrades to evolve the current single-page tracker into a fault-tolerant, sensor-driven platform.

🛡️ Pillar 1: System Reliability & Sync
1. Offline Write Queue (Background Sync)

Current app caches reads offline but requires network for DB writes. Upgrade to an IndexedDB Outbox Queue that buffers offline mutations and replays them automatically when connectivity returns.

2. Server-Side Cron Rule Evaluation

Move weather polling and Gate P0 evaluation into a daily 05:30 AM Supabase Edge Function (`pg_cron`) so schedule shifts happen automatically even before the app is opened.

3. Optimistic Concurrency & Row Versioning

Add a `version_int` column to `daily_task_queue` so two users updating the same card simultaneously on different phones never overwrite each other's item statuses.

🎯 Pillar 2: Agronomic & Microclimate Accuracy
1. Growing Degree Days (GDD) vs. Calendar DAD

Replace static calendar Days After Defoliation with thermal time ($\text{GDD} = \sum (\frac{T_{\max} + T_{\min}}{2} - T_{\text{base}})$). Warm El Niño months accumulate heat faster, shifting stage transitions dynamically.

2. Disease Infection Index (Temp × RH × Leaf Wetness)

Compute a daily Bacterial Blight & Fungal Risk Score from rolling 72-hour humidity ($>80\%$) and night temperatures, automatically tightening spray intervals from 7 days to 4 days during high-risk windows.

3. Cumulative Nutrient Ledger (NPK Target vs. Actual)

Track cumulative grams of Elemental N, P, K, Ca, and Mg delivered per plant across the season against target stage curves, rather than only compensating the single next task.

⚙️ Pillar 3: Operational Robustness
1. Automated Shed Inventory Deduction

Link `shed_leftovers` directly to task completion: marking an item `COMPLETED` automatically deducts `actual_total_qty` from shed stock, and logging a store bill increments shed stock.

2. Multi-Block / Multi-Crop Partitioning

Filter `daily_task_queue` by `block_id` in the UI header so the same architecture can manage multiple orchard plots or secondary crops with independent schedules.

3. Automated Snapshot & CSV/JSON Backup

Add a 1-click local export/import utility and weekly automated database snapshots so historical spray and expense records can never be lost.
